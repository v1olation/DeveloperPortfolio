# ShellScripts

These Bash examples are prepared for the capstone repository. They use standard Linux/WSL commands and do not modify source data.

- `script6_sysreport.sh` — reports hostname, date, kernel, uptime, memory, disk usage, and top processes.
- `file_summary.sh` — counts files and directories and reports total size for one directory.

Run from the repository root with `bash ShellScripts/script6_sysreport.sh` or `bash ShellScripts/file_summary.sh PATH`. Add the original Lab 2 scripts when located; these examples do not replace historical lab evidence.
